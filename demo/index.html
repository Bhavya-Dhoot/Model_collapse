How much real data keeps a generative model from eating itself?

Tabular synthesizers are increasingly retrained on data that earlier synthesizers produced. That closed loop degrades the model. Keeping a fraction α of genuinely real rows in every training set arrests it. We solve that loop exactly for Gaussian fitting, and measure what actually happens on three real benchmarks.

Bhavya Dhoot, Yashee Hinger, Karthik G. M. · Vellore Institute of Technology · every number below is recomputed live from the released results/main.csv.

04 · The negative result

The classic warning sign never fires

Model collapse is usually described as variance contraction. For a rank-based copula it does not happen: the marginal transform re-normalizes spread every generation, so variance stays flat while the model rots on every other axis. A variance monitor would report health.

05 · Why one number is not a specification

Every axis has its own threshold

α★ is the smallest real-data fraction that keeps an axis within tolerance — and stays within it for every larger α, so a single noisy dip is not mistaken for a threshold. The axes disagree by a factor of 2.7 on Adult.

06 · Scaling

Bigger datasets need less anchoring — far less quickly than theory promises

The closed form predicts α★ ∝ 1/n. Measured across seven budgets the exponent is 0.26, with a bootstrap interval that excludes 1 by a wide margin. The closed form is an optimistic bound, not a recommendation.

07 · Not all real data is equal

A lost category only comes back in a row that contains it

Numeric drift is a contraction: any real data pulls it back. Losing a rare category is closer to an absorbing state. So it matters whether the anchor rows are re-used (fixed) or freshly drawn each generation (fresh) — and it matters on exactly one axis.

08 · Does it generalize?

Two findings survive the change of architecture

The exact theory covers Gaussian fitting only. Qualitatively, though, all three synthesizers lose categorical support under self-consumption and recover it under anchoring — and none of them shows the clean variance contraction the Gaussian recursion predicts.
